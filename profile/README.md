**Keebdex** is the collector's index of artisan keycaps, keysets, and keyboards, and the place to keep track of your own collection. Look up any maker, sculpt, colorway, keyset, or group buy from one search.

[keebdex.org](https://keebdex.org) · [About](https://keebdex.org/about) · [Why Choose Keebdex?](https://keebdex.org/why-choose-keebdex) · [Changelog](https://keebdex.org/changelog) · [Brand Guidelines](https://keebdex.org/brand)

### Repositories

| Repository | What it does |
| --- | --- |
| [keebdex](https://github.com/keebdex/keebdex) | The Keebdex web app, built with Nuxt and Supabase. |
| [catalog-sync](https://github.com/keebdex/catalog-sync) | Collects and syncs artisan, keyset, keyboard, and image data from Google Docs and maker or vendor websites into the catalog. |
| [press-kit](https://github.com/keebdex/press-kit) | Official logos, marks, colors, and banners. |
| [image-resizer](https://github.com/keebdex/image-resizer) | A command-line tool that squares PNG images and trims their transparent padding. |

### Contributing

Anyone signed in on [keebdex.org](https://keebdex.org) can propose new entries, fix details, and add photos from any page; moderators review each change before it goes live. Bugs and ideas for the app are welcome as [issues](https://github.com/keebdex/keebdex/issues).
